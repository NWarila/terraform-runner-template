# Architecture Decision Records

This directory contains the Architecture Decision Records (ADRs) for this
template repository.

ADRs are organized into two scopes per
[org ADR-0001](https://github.com/NWarila/.github/blob/main/docs/decision-records/0001-use-architecture-decision-records.md):

- `org/` — byte-identical mirrors of org-baseline ADRs from `<owner>/.github`.
- `repo/` — repository-specific ADRs.
